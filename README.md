# 📸 InstaQR Generator

A simple, modern, and responsive Instagram QR Code Generator built using HTML, CSS, and JavaScript.

Enter an Instagram username and generate a QR code that can be scanned to open the profile directly in a web browser.

## ✨ Features

- 📸 Instagram profile QR generator
- ⚡ Instant QR code generation
- 📱 Responsive design
- 🎨 Modern glassmorphism UI
- 🌈 Animated gradient background
- 🔗 Direct Instagram profile URL
- 🚀 Lightweight and fast
- 💻 Built with pure HTML, CSS & JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- QRious QR Code Library

## 🚀 How to Use

1. Enter an Instagram username.
2. Click **Generate QR Code**.
3. Scan the generated QR code.
4. The Instagram profile will open in your browser.
